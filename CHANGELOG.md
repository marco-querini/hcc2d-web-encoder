# Changelog

All notable changes to this project are documented here.

## 0.9.0 - 2026-10-11

- First public release.
- Client-side QR Code, HCC2D4, and HCC2D8 PNG generation from text, files,
  URLs, and vCards.
- Model 1, Model 2, and validated custom HCC2D4 palettes.
- Responsive light and dark interfaces with service-worker caching.
- Source, structural, and Chromium browser tests.
